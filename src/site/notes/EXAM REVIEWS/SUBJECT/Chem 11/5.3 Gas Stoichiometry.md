# 5.3 Gas Stoichiometry
#### Daltons Law of Partial Pressure
- $P_t = P_1 +...+ P_m$ 
- Since in PV = nRT, in a fixed environment, ONLY the mol is changing, we can treat them like fixed variables
- $\rightarrow  P_t = (n_1 +...+n_m)\frac{RT}{V}$
